# Security and Spoiler Policy

This repository documents learning from the OverTheWire Bandit wargame.

It intentionally does **not** publish:

- Bandit passwords;
- private challenge credentials;
- direct level-by-level answer strings;
- copy-paste final solutions.

The purpose of the repository is to document:

- Linux concepts;
- security reasoning;
- commands and techniques;
- progression in problem solving.

Readers should use the official Bandit environment to solve the challenges themselves:

https://overthewire.org/wargames/bandit/

## Why the Repository Is Spoiler-Safe

The private study material used to create these notes contained credentials and direct completion details.

Those values were removed from the public version.

This preserves the educational value of the game while still making the learning outcomes inspectable.
